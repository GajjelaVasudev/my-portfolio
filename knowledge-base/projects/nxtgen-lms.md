# NxtGen LMS — Learning Management System

## Project Overview
- **Project Name**: NxtGen LMS
- **Category**: Learning Management System / Educational Web Application
- **Status**: Completed & Deployed on Vercel
- **Repository URL**: https://github.com/GajjelaVasudev/NxtGen-LMS
- **Live Demo URL**: https://nxt-gen-lms.vercel.app
- **Featured Project**: Project 01 in Vasudev's Selected Work

## Architecture & Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, modern responsive UI
- **Backend**: Node.js, Express, RESTful API architecture
- **Database**: Supabase (PostgreSQL) with structured relational schemas
- **Deployment**: Vercel for frontend hosting

## Implemented Features & Workflows
- **Role-Based Access Control (RBAC)**: Dedicated workflows and permissions for Administrators, Instructors, Course Creators, and Students.
- **Course & Content Management**: Allows instructors to create, organize, and publish modular courses, syllabus materials, and multimedia learning resources.
- **Enrollment & Participation**: Seamless course enrollment mechanics, student roster management, and tracking of active learners.
- **Assignment Submissions**: Digital assignment submission interface supporting deadlines, file attachments, and submission status tracking.
- **Dynamic Assessment Scoring & Progress Tracking**: Automated quiz evaluations, grade calculation, and longitudinal student progress visualization.
- **Relational Data Modeling**: Designed scalable PostgreSQL database schemas to efficiently organize users, courses, assignments, and enrollment metrics.
